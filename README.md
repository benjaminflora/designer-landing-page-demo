# Northstar Studio Demo Landing Page

This repository contains a polished mock landing page designed for a design-review or client demo.

## Preview locally

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

This is intentionally styled as a clean, modern portfolio/agency landing page for demo purposes.
